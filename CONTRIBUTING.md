# Contributing to Focus-lock

Thank you for your interest in contributing to Focus-lock!

Focus-lock is an open-source Android productivity and digital wellbeing project. Contributions, suggestions, bug reports, and improvements are welcome.

## 🐛 Reporting Bugs

Before opening an issue, please check whether the problem has already been reported.

When reporting a bug, include:

- A clear description of the problem
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Android version
- Device information, if relevant
- Screenshots or logs when useful

## 💡 Feature Requests

Feature suggestions are welcome.

Please explain:

- What the feature should do
- Why it would be useful
- How you think it could improve Focus-lock

## 🔧 Pull Requests

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test the changes on an Android device or emulator.
5. Keep the changes focused and well documented.
6. Submit a pull request with a clear description.

## 🧪 Testing

Please test changes before submitting a pull request, especially features related to app blocking, website blocking, timers, scheduling, and protection mechanisms.

## 📜 Code of Conduct

Please be respectful and constructive when participating in the project.

Thank you for helping improve Focus-lock!
