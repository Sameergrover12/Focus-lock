Focus-lock

An open-source Android productivity and digital wellbeing app designed to help you stay focused and reduce digital distractions.

Focus-lock helps users take control of their screen time by blocking distracting websites and applications, setting usage timers, and creating focused periods for work or study.

«🚧 Focus-lock is currently under active development. Features and the user interface are continuously being improved.»

✨ Features

- 🚫 Website Blocking — Block distracting websites during focused periods.
- 📱 App Blocking — Restrict access to selected applications.
- ⏱️ App Timers — Set time limits for applications.
- 🎯 Focus Sessions — Create dedicated periods for uninterrupted work or study.
- 📊 Productivity Control — Reduce unnecessary screen time and digital distractions.
- 🔓 Open Source — The project is publicly available for transparency and community contribution.

🎯 Why Focus-lock?

Modern smartphones make it extremely easy to lose focus through social media, entertainment, and other distracting applications.

Focus-lock is being built to provide a simple, accessible, and open-source way for users to regain control over their digital habits.

The goal is not to remove technology from people's lives, but to help them use it intentionally.
